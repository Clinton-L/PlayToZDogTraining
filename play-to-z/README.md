# PlayToZ Dog Training

## Visual theme

The site uses a custom PlayToZ visual theme; it is not based on an imported UI theme or component library. The direction is warm, outdoorsy, and editorial, pairing deep greens with lively coral and sunny yellow accents.

Typography is loaded from [Google Fonts](https://fonts.google.com/): DM Sans for interface and body text, and Fraunces for expressive headings.

### Color guide

| CSS token | Hex | Use |
| --- | --- | --- |
| `--ink` | `#26372F` | Main text and high-contrast details |
| `--muted` | `#647269` | Supporting text and secondary labels |
| `--paper` | `#F8FAF5` | Page background |
| `--line` | `#D8E0D7` | Rules, borders, and dividers |
| `--green` | `#345846` | Primary actions and large brand bands |
| `--coral` | `#E86F59` | Links, highlights, and active navigation |
| `--yellow` | `#F1C84C` | Small emphasis details and callouts |
| `--sky` | `#D9EDF0` | Cool supporting surface |

Supporting colors used in the interface: white (`#FFFFFF`) for contrast on green, deep green (`#253F31`) for primary-button hover, and pale green (`#D7E8D9`) for text on the green callout band. The header uses a translucent paper background (`rgba(248, 250, 245, 0.96)`).
